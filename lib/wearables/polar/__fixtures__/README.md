# Fixtures Polar AccessLink

Réponses JSON réelles capturées par `npm run polar:spike` (POL-03), puis anonymisées :
identifiant utilisateur Polar → `123456`, `member-id` → `member-fixture`,
`device_id` → `DEVICE00`, nom/prénom/date de naissance/poids/taille remplacés,
jeton d'accès remplacé par `fixture-access-token`.

Relire chaque fichier avant de le commiter : les dates, horaires et mesures
(sommeil, FC, pas) sont réels.
